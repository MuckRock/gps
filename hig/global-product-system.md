# Global Product System

Figma: [https://www.figma.com/design/Xsvs67pFwXoxTZWtCQSRXW/Global-Product-System?node-id=0-1&p=f&m=dev](https://www.figma.com/design/Xsvs67pFwXoxTZWtCQSRXW/Global-Product-System?node-id=0-1&p=f&m=dev)

The Global Product System is a set of common colors, type styles, components and design patterns used across MuckRock products.

This system reflects decisions we made and patterns we extracted from DocumentCloud and have since used on Klaxon Cloud and MuckRock Accounts. It is a newer design system than what is currently in use on MuckRock. It should inform and power the next version of MuckRock and future tools.
